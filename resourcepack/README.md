# Accessories resourcepack

Добавьте PNG-файлы, перечисленные ниже, в указанные папки. Имена должны совпадать с JSON-моделями:

```text
assets/core/textures/item/accessories/ring_ruby.png
assets/core/textures/item/accessories/emblem_warrior.png
assets/core/textures/item/accessories/emblem_archer.png
assets/core/textures/item/accessories/emblem_mage.png
assets/core/textures/item/accessories/necklace_basic.png
assets/core/textures/item/slots/slot_necklace.png
assets/core/textures/item/slots/slot_emblem.png
assets/core/textures/item/slots/slot_ring.png
assets/core/textures/item/slots/slot_locked.png
assets/core/textures/item/button_accessories.png
```

`assets/minecraft/items/` выбирает модель по `custom_model_data`, а модели в `assets/core/models/item/` используют эти текстуры.
